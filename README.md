# Felix Pasillas's Portfolio

A single-page portfolio showcasing my work as a full-stack web developer: an introduction, featured projects, skills, and ways to get in touch. Fully responsive, with a mobile navigation menu.

**Live site:** https://portfolio-git-sprint-12-fpasillas.vercel.app

## Stack

- React + TypeScript, built with Vite
- Plain CSS with BEM naming and media queries for responsive layouts
- ESLint and Prettier for linting and formatting
- GitHub Actions CI (build, lint, and format checks)
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```
